# GitHub issues own the implementation roadmap

GitHub issue bodies, native sub-issues, native dependencies and explicit work
labels are the sole owners of implementation plans and execution state. A small
metadata-only reconciler derives readiness labels from those facts. Repository
documents continue to own scientific equations, accepted requirements, numerical
evidence and capability qualification; local roadmap tables and rendered status
copies are retired because they created competing mutable state. This supersedes
only ADR 0008's local implementation-plan ownership clause.
