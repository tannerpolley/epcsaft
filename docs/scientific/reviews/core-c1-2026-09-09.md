# Core C1 design and qualification record

Date: 2026-09-09
Issue: [#215](https://github.com/tannerpolley/ePC-SAFT/issues/215)
Scope: Core constants, physical bounds and numerical-policy meanings only
Qualification status: qualified on 2026-09-10 after final independent `Ship` review

## Slice

C1 is a capability slice. It establishes the shared numeric owners consumed by
the current native calculations and removes one demonstrated cross-unit policy
use. It does not change parameter coordinates (C2), diagnostic states (C3),
the equilibrium method, association harnesses, notebooks or applications.

The affected runtime owners are:

- `engine/native/core/physical_constants.hpp`: SI constants and unit bridges.
- `engine/native/core/numerical_policy.hpp`: constraints, tolerances, search
  bounds and budgets.
- `engine/native/contributions/electrolyte.hpp`: reuse of named SI/angstrom
  bridges.
- `engine/native/equilibrium/gibbs_minimizer.cpp`: logarithmic composition
  bounds and free-phase disappearance predicate.

Direct consumers were traced in `contributions/`, `properties/`,
`equilibrium/`, `core/convergence.hpp` and the native checks. Existing callers
already provide the required scales: molar density is mol/m^3, geometry is in
angstrom, dipoles are in Debye, compositions and packing fractions are
dimensionless, and equilibrium rows are explicitly scaled residuals.

The build correction is explicit: `contributions/electrolyte.hpp` will use
`NUMBER_DENSITY_PER_ANGSTROM3` for its molar-to-angstrom number density and
`ANGSTROM_M` for its Debye-diameter length conversion. No duplicate conversion
literals are retained in that consumer.

## Policy decisions

`Tolerance::value` is a numeric quantity in the unit stated below; `source`
records provenance or provisional status and is not an accuracy certificate.
Budgets and branch switches are not thermodynamic constraints.

| Policy family | Unit/scale and predicate | Failure meaning |
|---|---|---|
| `CLOSE_PACKING_FRACTION` | dimensionless packing fraction; reject `eta >= eta_max` | conservative hard-sphere PC-SAFT admission bound, not a mathematical singularity claim |
| `SITE_FRACTION_FLOOR`, `SITE_FRACTION_CEILING` | dimensionless site probability; require `0 < X_a <= 1` | association state/domain failure |
| `ASSOCIATION_RESIDUAL` | dimensionless infinity norm of mass-action residual; accept `<=` | association convergence criterion |
| `ASSOCIATION_MAX_ITERATIONS` | iteration count budget | exhausted association solve is not success |
| `ASSOCIATION_JACOBIAN_CONDITION` | dimensionless relative pivot floor | dense Newton step is ill-conditioned; substitution fallback/failure |
| `DENSITY_ROOT_RESIDUAL` | dimensionless reduced pressure residual; accept `<=` | density root did not meet its declared residual |
| `DENSITY_MAX_ITERATIONS`, `DENSITY_BRACKET_INTERVALS` | counts | refinement/search work limits, never accuracy claims |
| `DENSITY_LOWER_FRACTION`, `DENSITY_UPPER_FRACTION` | dimensionless fractions of ideal-density and admitted upper-density scales | finite search interval only |
| `DENSITY_BISECTION_FRACTION` | dimensionless interpolation fraction in [0,1] | safeguarded candidate selection |
| `COMPOSITION_SUM_TOLERANCE` | dimensionless absolute sum error | reject invalid normalized composition |
| `REFERENCE_MOLALITY_*` | mol/kg salt-free solvent | fixed reference ladder inputs, not convergence error |
| `REFERENCE_CONVERGENCE_WITNESS` | dimensionless log-fugacity witness | terminal-limit recheck scale |
| `REFERENCE_CONVERGENCE_TOLERANCE` | dimensionless log-fugacity difference | reference ladder did not close |
| `STABILITY_CANDIDATE_GAP` | dimensionless reduced Gibbs gap | candidate acceptance gap in Pereira's criterion; no global certificate |
| `STABILITY_COMPOSITION_FLOOR` | dimensionless intensive composition coordinate; `ln(x_i)` lower bound | log-coordinate domain only |
| `STABILITY_PHASE_AMOUNT_FLOOR` | dimensionless `n_phase / sum(n_feed)`; compare `<=` only for free-phase disappearance | numerical topology rejection; not a stability or thermodynamic conclusion |
| `STABILITY_MULTIPLIER_GAP` | dimensionless relative multiplier/gradient gap | candidate criterion only; currently not wired in the installed search |
| `STABILITY_COMPOSITION_GAP`, `STABILITY_PACKING_GAP` | dimensionless composition/packing distances | candidate distinctness criterion only; no current search claim |
| `EQUILIBRIUM_ROW_RESIDUAL` | dimensionless scaled row infinity norm; accept `<=` | shared driver residual criterion |
| `EQUILIBRIUM_MAX_ITERATIONS` | iteration count budget | optimizer work exhaustion |
| `PHASE_COINCIDENCE_DISTANCE` | dimensionless max of log-packing and composition distances | declared phases numerically coalesced |
| `PACKING_FRACTION_CEILING` | dimensionless solver coordinate ceiling below close packing | finite optimizer domain, not physical close packing |
| `STABILITY_SEARCH_BUDGET` | evaluation count budget | bounded search is incomplete; exhaustion is not stability |
| `SCREENING_SERIES_SWITCH` | dimensionless `kappa*d` | choose cancellation-safe series branch; both branches represent the same relation |
| `FLOOR_MARGIN` | dimensionless multiplier of a supplied residual floor | provisional `converged_to_floor` classification; not an error bound |
| `STALL_WINDOW` | count of residual samples; geometric contraction over that window | provisional stall/budget heuristic; not an Ipopt accuracy criterion |

### Open convergence calibration choices

`FLOOR_MARGIN=10` retains the provisional rationale of a guessed decade of
slack across the first-order bound's norm inequalities. Its actual predicate is
`residual <= FLOOR_MARGIN * floor`, and its failure meaning is classification
as `converged_to_floor`, not an accuracy certificate. `STALL_WINDOW=5` retains
the provisional rationale of a guessed window below Ipopt's acceptable-iteration
default of 15. Its actual predicate is the residual-history contraction window,
and its failure meaning is a stall/budget classification, not an optimizer
accuracy criterion. Their numerical adequacy and calibration remain open C3
choices; C1 does not claim that either value is accurate or optimal.

### Composition/amount resolution

The inner problem stores `ln(x_i)` for positive intensive composition
coordinates. Therefore `STABILITY_COMPOSITION_FLOOR = 1e-8` remains a
dimensionless composition-domain bound and is used only in
`get_bounds_info()`.

The free phase amount `n_p` is extensive in the resolved feed basis. Its raw
value changes when the same feed is rescaled, so an absolute comparison in mol
or feed-basis units is not invariant. The disappearance predicate is instead

\[
  f_p = n_p / n_{\mathrm{feed,total}},\qquad
  f_p \le \texttt{STABILITY\_PHASE\_AMOUNT\_FLOOR}.
\]

`STABILITY_PHASE_AMOUNT_FLOOR` retains the existing `1e-8` numerical cutoff
as a separate, explicitly provisional topology policy. The comparison uses
the already validated positive `feed_total`; it is invariant under a common
positive rescaling of feed and phase amounts. A rejected near-zero phase is
reported as a topology/absence failure, not as evidence of global stability.

The close-packing value is the equal-sphere face-centred-cubic reference used
as a conservative admission limit for the current hard-sphere PC-SAFT
correlation. The mathematical logarithm itself remains defined for this
correlation below `eta = 1`; crossing the conservative admission value is a
domain rejection, not proof of a singularity. Mixture-specific packing
validity remains outside C1.

## Falsifiers and preserved cases

1. Compile-time/value checks verify `R = N_A k_B`, `D*c = 1e-21 C m^2/s`,
   `ANGSTROM_M = 1e-10 m/angstrom`, and
   `NUMBER_DENSITY_PER_ANGSTROM3 = N_A*ANGSTROM_M^3`. The epsilon record
   retains the 2018 CODATA central value and source uncertainty.
2. The source audit checks that the electrolyte consumer uses the two named
   Core bridges and contains neither duplicate `1e-30` nor duplicate `1e-10`
   conversion. The bridge identity checks include
   `NUMBER_DENSITY_PER_ANGSTROM3 = N_A*ANGSTROM_M^3` within double precision.
3. The existing packing, association, density, reference-ladder and
   equilibrium residual checks remain unchanged except for the named policy
   ownership and must retain their current numerical rows.
4. The existing phase-absence case uses
   `properties_support::aqueous_electrolyte()`, `T=298.15 K`, `P=1e5 Pa`, a
   molality feed `{0,1,1}`, and vapor support restricted to the zero-feed
   component. It must still reject a truly vanished free phase. The exact
   scale-pair case uses `properties_support::neutral_binary()`, one liquid
   phase from `equilibrium_support::flash(2)`, `T=300 K`, `P=1e5 Pa`,
   `FeedKind::Amounts`, and feeds `{0.5,0.5}` and `{5e-10,5e-10}`. Both
   solutions must succeed with the same phase topology; each phase amount
   divided by its feed total must be `1.0` within `1e-7`. The scaled amount is
   below the former absolute `1e-8` cutoff, so this falsifies that use.
5. `DEBYE_C_M` is retained and value-tested because the C1 question requires
   the SI/Debye bridge, but it has no current runtime consumer: the active
   dipolar EOS input uses the source equation's `mu^2 1e-19` convention. C1
   makes no claim that this unused bridge is exercised by the installed Engine.
6. No tolerance is widened to accommodate the constant audit. Existing F5
   weighted-curvature disagreement remains a separate historical failure and
   is not a C1 acceptance criterion.

## Acceptance boundary

The C1 claim is limited to meanings, units, source status, scale-invariant
phase-absence classification and the listed reference cases; it does not
qualify the unwired stability search or any later Core row.

## Implementation qualification note

The installed solver keeps the Gibbs objective extensive but normalizes
material-balance rows by the feed total. The implementation therefore applies
Ipopt's positive internal objective scale `1 / feed_total`; this preserves the
minimizer and keeps the objective derivatives numerically comparable for
rescaled feeds. A tiny-step Ipopt exit is accepted only when the recomputed
equilibrium residual satisfies `EQUILIBRIUM_ROW_RESIDUAL`. The C1 scale pair
then succeeds at feeds `{0.5,0.5}` and `{5e-10,5e-10}`, with normalized phase
amount `1.0` within `1e-7`; this is solver-conditioning evidence in addition
to the policy-predicate falsifier, not a claim about arbitrary feed scales.
Ipopt returns final constraint multipliers already unscaled to the original
extensive-objective meaning; the Engine preserves them without an extra
feed-total conversion.
