## Bounded capability

C3 makes the existing Core convergence records truthful at non-finite and
producer-boundary cases, and keeps an unavailable equilibrium result distinct
from an available state. It reuses `Convergence`, `ConvergenceFailure`,
`EquilibriumResult::solver_status`, and `EquilibriumResult::has_state()`; it
adds no lifecycle, retry, tolerance, numerical method, selector, or
specification framework.

The accepted stop meanings are:

| Stop | Meaning | Available result? |
|---|---|---|
| `converged` | finite residual meets its declared criterion | yes, if the producer accepts the result |
| `converged_to_floor` | finite residual is above the criterion but within the existing provisional floor margin | yes only where the producer explicitly accepts it |
| `stalled` | finite non-converged work without declared budget exhaustion | no |
| `budget_exhausted` | finite non-converged work reaches its declared budget | no |
| `nonfinite` | residual, floor, contraction, or amplification is NaN or infinite | no |
| `left_domain`, `singular`, `infeasible` | existing typed producer conditions | no |

`nonfinite` is checked before finite convergence and floor predicates. An
unsuccessful equilibrium result retains native solver status, residuals, the
convergence record, and its failure message while clearing candidate state;
`has_state()` remains the availability predicate. A successful result retains
the same convergence record alongside its state. Missing optional diagnostics
remain absent rather than being replaced with zero.

## Correction scope (2026-09-10)

The prior record overstated two boundaries. The equilibrium producer must pass
`budget_hit` only for actual Ipopt work-budget statuses
(`MAXITER_EXCEEDED` and `CPUTIME_EXCEEDED`); `STOP_AT_TINY_STEP` with a finite
non-converged residual is `stalled` and unavailable, while the existing finite
tiny-step convergence remains available. Density `refine` and `anchor` must
also reject a criterion-meeting candidate when `core::classify` returns
`nonfinite` because an optional diagnostic is nonfinite. The correction keeps
the existing `ConvergenceFailure` path and must preserve a finite root that
reaches the criterion at the iteration cap.

The correction falsifiers are: a finite non-converged tiny-step topology case
must report `stalled` rather than `budget_exhausted`; a valid finite density
root must remain available; and nonfinite density diagnostics must produce an
unavailable `ConvergenceFailure` before either root producer publishes a
candidate.

## Scientific ownership and changed seams

precedence and equilibrium availability meaning. The implementation traces
through these existing owners:

| Owner | C3 behavior |
|---|---|
| `core/convergence.hpp` | classify non-finite diagnostics as `Stop::nonfinite`; reject non-finite history samples |

  monotone across convergence, floor, budget, and stall cases; NaN, positive
  infinity, negative infinity, and infinite optional diagnostics are rejected.
- `native.diagnostics.c3-producers`: association overflow produces
  `nonfinite`; a negative-density site solve produces `left_domain`.
- `native.equilibrium.c3`: the existing vanished-phase fixture retains
  `STOP_AT_TINY_STEP`, `stalled`, finite residual rows, and its reason while
  clearing state; a one-phase fixture retains available state and convergence

- `native.diagnostics.c3-density`: a valid finite root remains available; a

  the shared publication boundary; and a finite criterion root remains

## Limits

not qualify arbitrary Ipopt statuses, source parameter ranges, global phase

`FLOOR_MARGIN=10` and `STALL_WINDOW=5` policy. The pre-existing pinned F5
