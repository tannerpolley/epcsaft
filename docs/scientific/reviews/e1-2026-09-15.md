## Correction

The current shared compiler returned an all-zero Hessian whenever any phase
amount was pinned. The existing F5 baseline therefore retained 42 false
pinned comparisons at each objective factor 0, 0.5, and 1 while the regular
case passed; the original failures remain in
[the Core F5 evidence](core-c1-2026-09-10.csv). The same failure was reproduced
from current `main` before this correction.

`CompiledSystem::hessian` now evaluates the complete multiplier-weighted
chemical, pressure, balance, charge, and normalization curvature at the
callback point's actual free or fixed temperature and pressure. The pinned
objective remains constant, and `GibbsMinimizer::eval_h` remains the sole
objective-factor owner.

Properties supplies one native third directional contraction through the
existing Helmholtz tape, implicit association Taylor coefficients, and site
factorization. It runs under the existing model mutex and adds no tape,
derivative engine, dense third-order tensor, solver, Python API, or physical
model. The accepted `weighted_lagrangian_hessian` equation and
`ALG-EQUILIBRIUM` are revalidated without changing tolerances.
