# Paper figures from promoted retained results

Regenerate from the repository root with `nice -n 10 .venv/bin/python docs/scientific/latex/scripts/figures.py`.

The script is the single figure owner. It reads CSV and JSON Git objects at the investigator-promoted commits from [the first owner promotion](https://github.com/tannerpolley/ePC-SAFT/issues/501#issuecomment-6373385229) and [the second owner promotion](https://github.com/tannerpolley/ePC-SAFT/issues/501#issuecomment-6376503363). The computational-cost figure uses the separately investigator-promoted result commit listed in its entry below. It does not import the Engine or calculate a new thermodynamic state. Every new PDF is vector output at 7.1-inch two-column width; dense galleries use multiple pages. The four earlier PDFs retain their original drawing functions and dimensions.

`supplementary-comparisons.csv` is the reader-facing comparison table distributed with the supplement, with values rounded to four significant figures. `T10-master-table.json` retains full-precision metrics, comparison populations, conditions and limits. A visual panel may have separate table rows for parameter variants, reference roles and training/withheld populations; those rows do not add independent observations. `sources.json` gives exact promoted commits, paths and SHA-256 values. `figure-notes.json` gives panel membership and caption limits; source membership is recorded here. `plotted-comparisons.json` retains ordinary paired series; categorical, projected and algorithm series are read directly from the exact source files.

AARD is the mean absolute relative difference times 100; RMS is the square root of the mean squared direct difference; MAE is the mean absolute direct difference. Maxima state their quantity and unit. Missing values stay outside arithmetic and inside coverage counts. No unavailable value becomes a zero. Metrics against digitized model lines describe reproduction, not measured accuracy. In mixed-convention or mixed-declaration panels the metric includes both, as identified in each table note.
