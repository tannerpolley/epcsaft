# Theory

These pages are the Engine's scientific specification: the equation registry,
the numerical algorithms, the EOS sources and conventions, the equilibrium
formulation and pure-component parameter estimation. Each equation states its
source and whether it is a source equation, an exact derivation or an
implementation convention. A registered equation does not by itself mean that
every use of it is available; the [limits page](../limits.md) and the
[user guide](../guide/index.md) state what is supported.
