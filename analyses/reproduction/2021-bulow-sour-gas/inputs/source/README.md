# Source and replay boundary

The primary source is the local Zotero Markdown extraction identified in
`source-manifest.csv`. Article locations in the retained CSV files refer to
that extraction. The source reports Figure 4–10 curves and headline ARDs but
does not contain the plotted numeric point arrays. The 45-page supporting
information is bound by path and SHA-256 in `source-manifest.csv`; its exact
Tables S3 and S4 ARDs are transcribed in `bulow-2021-si-tables.csv`.

`binary-figure-digitized.csv` contains an explicitly approximate visual
digitization of article Figures 1 and 3. Those values are diagnostic inputs,
not original tabulated measurements. The ARDs in `paper-result-summary.csv`
and `bulow-2021-si-tables.csv` remain source claims rather than generated
results. Reactive Figure 4–10 point arrays still require original tables or a
separately recorded digitization with exact loading and pressure bases.
