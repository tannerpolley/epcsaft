| Check | Numerical rule |
|---|---|
| Property bundle | absolute difference ≤ 1e-08 × max(absolute values, 1 in each reported unit) |
| Pressure-state density | relative difference ≤ 1e-10 |
| Equilibrium pressure and density | relative difference ≤ 1e-07 |
| Equilibrium mole fractions and phase fractions | absolute difference ≤ 1e-08 |
| Exact actions versus central differences | absolute difference ≤ 2e-08 + 2e-05 × max(absolute action values) |
| Repeated timed returns versus preflight | absolute difference / max(absolute values, 1 in each reported unit) ≤ 1e-10 |
| Electrolyte component balance, charge and mole-fraction sum | absolute difference ≤ 1e-10 |
