# Pure-saturation source contract

`propane-baseline.csv` contains three independent coexistence states selected
from Glos, Kleinrahm, and Wagner (2004), Table 2. The fit uses saturation
pressure and saturated-liquid mass density at 210 K, 270 K, and 330 K.

The rows are calibration evidence, not expected model output. This campaign
makes no held-out predictive-accuracy claim.
