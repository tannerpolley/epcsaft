# Scientific analysis sets

Each leaf under `analyses/` owns one scientific question. Literature,
experimental, standard, and prior-result reproductions use
`analyses/reproduction/<short-id>/`; other analyses use
`analyses/<short-id>/`. A leaf retains only populated `inputs/`, `scripts/`,
`results/`, `figures/`, or `tests/` directories, plus an existing reviewed
`notebook.qmd` and a concise `README.md` when needed.

The nested `reproduction/` category is this repository's documented extension
to the CSE default. Name the complete leaf in every workflow stage, for example:

```text
cse:analyze analyses/reproduction/2026-khudaida
cse:review analyses/reproduction/2026-khudaida
```

Do not invoke the CSE setup helper with a nested identifier, store scientific
files directly under `analyses/reproduction/`, or treat the category as one
combined analysis set. Historical path strings inside retained results remain
provenance rather than live commands.

Executable shell blocks in analysis READMEs and notebooks advertise current
commands. Historical calculation methods are named in prose with their exact
retained wheel or record commit and retired interfaces; their obsolete rerun
recipes are removed. `tools/check-analysis-layout.py` checks advertised Python
commands against the current Engine exports without importing a wheel.

## Numbers in notebooks

Compute reported numerical values, counts, tolerances and comparison statistics
from retained CSV/JSON with Quarto inline Python or tables generated by cells
that read those files; do not type them into prose or literal Markdown tables.
Keep units, row selection, rounding and unavailable-value handling explicit.
Rendering reads retained results without running the Engine.
`tools/check-affected.sh` checks changed notebooks, and the tables of changed
leaf READMEs, for hand-typed numbers: a README links its notebook or retained
CSV instead of retyping a result table.
`python3 tools/check-notebook-numbers.py --all --counts` lists the notebook backlog.
These checks do not establish convergence or thermodynamic agreement.

## Analysis index

Each leaf owns its numbers; this index names only the question and status.
Status: **current** — retained evidence and current producers for the stated
scope; **diagnosis** — retained cause analysis; **record** — frozen numerical
evidence or a dated source survey, not rerunnable as a current-main calculation;
**pending live reproduction** — source inputs or historical results awaiting
the separate reproduction milestone. Current labels do not certify a fresh
main replay: the producer repairs and diagnoses in #720 remain separate work.
Figiel’s current source/ledger readers and the neutral comparison’s live listing
have narrower scope than their original frozen result rows.
The #234 native conversions and retirements are
recorded in the leaves they changed. The layout check rejects `scipy.optimize`
in Engine source, Engine tests and analyses; a zero count is lexical, not proof
that no Python thermodynamic calculation remains.
