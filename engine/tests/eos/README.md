# Public EOS test architecture

Every scientific test enters through the installed wheel's public `Pure`,
`Mixture`, `Parameters`, `ActiveParameterSet`, state, saturation, reference, or
observable methods. `_cases.py` owns compact source-neutral fixtures. The EOS
suite does not import `epcsaft._core`; packaging, Meson, link, symbol, wheel
origin, packet readiness, and import checks remain root/tool commands.

The exact single-node command for every row below is
`../.venv/bin/python -m pytest -q <node>` from `engine/`. The proportional group
command is `../.venv/bin/python -m pytest -q -m 'not slow and not expensive' tests/eos`.

Typed refusal nodes in `test_pressure_closure.py`, `test_reference_state.py`,
`test_saturation.py`, and `behavior/test_admission.py` have no numerical
tolerance: they assert public exception/status types and stable codes, never
exact messages, private shapes, iteration counts, or solver labels.

Broad fluid, literature, phase-equilibrium, fitting, and application evidence
is intentionally absent. It remains under explicit installed-wheel Validation
campaign commands.
