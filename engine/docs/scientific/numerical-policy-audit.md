# Engine numerical policy audit

Baseline: `d42c5cf9583b83976c782ae42c53aea38f3893bd` (`main`, 2026-08-30).

This audit covers caller-visible numerical policy in `engine/src/epcsaft/`,
`engine/cpp/equilibrium/`, and persistent Engine tests. Runtime searches covered
numeric literals, named tolerances, solver options, loop and search limits,
rank and conditioning rules, clipping, fallback, exception handling, and result
construction. Call traces start at the public Python methods and end at the
native owner named in each row. The untracked historical
`engine/docs/scientific/test-suite-audit/` proposal is not authority and was not
used.

Implementation statements and test descriptions below are **verified** against
the baseline source. Risk and recommendation statements are **inference** from
those verified paths. A justification cell says `none` unless a retained source,
equation, accepted decision, or falsifying test supports the choice. A passing
solver status is not physical acceptance; equation closure, first-order
optimality, local stability, derivative availability, covariance availability,
and search completeness remain separate claims.
