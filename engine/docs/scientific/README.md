# Engine scientific project records
This directory is the shared map for the Engine's formulation, numerical
methods, evidence, accepted decisions, and writing rules. Equations, source
provenance, executable methods, and retained numerical evidence stay in their
established owners; these records do not copy them.

The skeleton comes from CSE `v1.1.1`, annotated tag object
`30dbf25066b101e7282d49c7d508c69d3ce63db8`, commit
`29fa6a412afed46ff55baed8004531493078ef77`, and tree
`fbc2b22c411de79918e5144e83a0fceb236a7b51`. CSE issue 22 defines the
released migration used here.

- `CONTEXT.md` maps the scientific question and existing authorities.
- `formulation.tex`, `methods.tex`, and `evidence.tex` map the governing
  equations, computation, and verification or validation evidence.
- `adr/` is the sole accepted Engine decision-record sequence.
- `writing/` holds the scientific prose rules.
