# Engine domain authority

Before Engine shaping or implementation, read root `CONTEXT.md`,
`engine/CONTEXT.md`, `engine/ARCHITECTURE.yaml`, and the relevant accepted
decision under `docs/scientific/adr/`. Rebuild work also reads
`docs/greenfield/TRANSFER.md` and `engine/docs/agents/issue-tracker.md`.

Use the vocabulary defined by `docs/scientific/CONTEXT.md` in issues, code, evidence, and
reviews. Surface an ADR conflict before implementation; lifecycle state remains
in GitHub rather than being copied into domain documents.

The runtime lives under `engine/native/` and `engine/src/epcsaft/`, compact numerical falsifiers under
`engine/tests/`, and installed-wheel literature evidence under `analyses/`.
One Engine-accountable task may change the exact Data, Engine, and analysis
files required by its vertical slice.
